# OffMap

An offline mapping and location tracking application.

## Features
- Offline Map rendering and path traversal using Leaflet.js
- Local database storage using Dexie.js (IndexedDB wrapper)
- Capture & save map layouts with html2canvas.js
- Offline-first configuration and backup options.

## Files Included
- `index.html` - Core application layout and map render shell
- `leaflet.js` & `leaflet.css` - Map rendering utilities
- `dexie.min.js` - Client-side IndexedDB configuration
- `html2canvas.min.js` - Map capturing utility
- `backup.html` & `lay.html` - Backup and layout configurations
